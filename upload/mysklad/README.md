# Модуль МойСклад для OpenCart 4.1.0.3 (минимальный скелет)

В папке `upload/mysklad` лежит минимальная структура модуля с заглушками:
- admin/controller/... — контроллер админки
- admin/language/... — языковой файл
- admin/view/template/... — шаблон настроек
- catalog/controller/... — публичные точки (включая export/webhook)
- catalog/model/... — модель со заглушкой sync
- system/library/mysklad.php — библиотека-обёртка для API
- install.json — файл с параметрами установки

Как получить ZIP: я положил исходники в ветку "Ветка-вроде" под `upload/mysklad`. Если нужен реальный .zip-файл в репозитории, дайте знать, и я добавлю его (возможно, как бинарный файл). Сейчас добавлена текстовая заметка `releases/mysklad-opencart.zip` как заглушка.
